# 💎 Crypto Vault - Real-Time Portfolio Tracker

Live crypto prices, portfolio tracking, profit/loss—all in browser with **no backend**!

## ✨ Features
- 🔍 Search 10k+ coins via CoinGecko API (free, no key)
- 💼 Add holdings → auto-calculates value + PNL %
- 📊 Live dashboard: total value, PNL, coin count
- 💾 localStorage persistence (survives refresh/close)
- 📱 Fully responsive (mobile-first)
- 🔄 Auto-refreshes prices every 30s

## 🚀 Quick Start
1. Download ZIP or `git clone`
2. Open `index.html` in browser
3. Search "BTC" → Add holdings → Watch live PNL!

**No setup required** ✅
